# 🏛️ OSIRIS

**Organização Sistêmica de Investimentos, Receitas, Interações e Saldos**

Controle financeiro completo com:
- ✅ Login com email/senha
- ✅ Login com Google
- ✅ Dashboard com saldo e gastos
- ✅ Cadastro de transações
- ✅ Gerenciamento de categorias
- ✅ Perfil do usuário
- ✅ Tema escuro

## 🔗 Acesse

[https://nelsonsmartins.github.io/osiris-finance/](https://nelsonsmartins.github.io/osiris-finance/)

## 🗄️ Tecnologias

- React 18 (CDN)
- Supabase (Auth + Database)
- Tailwind CSS (CDN)
